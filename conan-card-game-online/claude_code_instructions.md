# Claude Codeへの指示文

このメッセージをそのままClaude Codeに貼り付けて使ってください。

## 依頼内容

私は2つのプロジェクトを持っています。

1. **名探偵コナンTCG価格集計サイト**（既存プロジェクト。GitHub Pages上で公開中）
   - GitHub Actionsで夜間スクレイピングを実行し、カード価格情報を取得している
   - このスクレイピング機能の中に、カードの画像URLや基本情報（カード名・ID等）を取得するロジックが含まれているはず

2. **名探偵コナンTCG AI対戦ビューア**（新規プロジェクト。Electron製のデスクトップアプリ）
   - 今回渡すzip（`conan-tcg-app-source.zip`）が本体
   - `board.html`：AI対戦の盤面ビューア（現状はモックデータのみ）
   - `deckbuilder.html`：デッキ作成画面（現状はサンプルカード20枚程度のみ）
   - `index.html`：ホーム画面
   - `main.js` / `package.json`：Electronの設定
   - `project_notes.md`：このプロジェクトのこれまでの設計方針・公式ルール全文（詳しくはこのファイルを読んでください）

## やってほしいこと

1. まず①の価格集計サイトのスクレイピング部分のコードを読んで、**カード画像・カード基本情報（カードNo/ID・カード名・種類・色・レベル・AP・LP・特徴・能力テキストなど）を取得しているロジックを特定**してください。

2. そのロジックを、**両方のプロジェクトから使い回せる共通モジュール**として切り出してください（例：`conan-card-scraper`のような独立パッケージ、または共通の関数群）。
   - 出力形式は、まとまったJSON（1カード1オブジェクト）が望ましいです
   - 画像はローカルに保存する形（URLだけでなく実ファイルとして持っておきたい）

3. 切り出した共通モジュールを使って、**AI対戦ビューア側（`conan-tcg-app-source.zip`）のカードデータベースを実データに置き換えて**ください。
   - `deckbuilder.html`内の`CARD_POOL`という配列が、現状ハードコードされたサンプルカードです。ここを実データ（取得したJSON）から動的に読み込む形に変更してほしいです
   - `board.html`側も、カード名や画像を表示している箇所を実データに対応できる形にしてください（今はテキストのみのプレースホルダー表示です）

4. 大量に取得する必要はありません。**最初は「スターターデッキ1つ分（20〜30枚程度）」など、範囲を絞って動作確認できるレベル**でまず動かしてください。全カード（2257枚）対応は後回しで構いません。

## 注意点

- `project_notes.md`に、このゲームの詳細ルール（公式ルールマニュアル全文）と、これまでの盤面デザインの方針、AIの意思決定優先順位などをすべてまとめてあります。**作業前に必ず目を通してください**。
- カード画像は公式サイトの版権画像です。個人利用の範囲（自分のPC上で動かすツール）に留め、再配布しないよう注意してください。
- デッキ構築ルールは「40枚ちょうど・同一カード3枚まで・キャラとイベントのみデッキに入れられる（パートナー・事件は別枠1枚ずつ）」です。`deckbuilder.html`の`MAX_COPIES`は既に3に設定済みです。
