# 名探偵コナンTCG AI vs AI リプレイビューア — プロジェクトメモ

## 1. プロジェクト概要
名探偵コナンTCGのAI同士の対戦を観戦できるリプレイビューアを開発中。
現状は「盤面デザイン（モックアップ）」+「Windows用exeパッケージ（Electron）」+「デッキ作成画面」が完成。
AIが実際にデッキを動かして対局する機能はまだ未着手。

---

## 2. ゲームルールの詳細（公式ルールマニュアル Ver.2.5 準拠・全文整理）
出典：https://www.takaratomy.co.jp/products/conan-cardgame/pdf/rule/rule_manual.pdf

### 2-1. カードの種類と見方
カードは以下4種類。
- **パートナーカード**：自分の相棒。事件解決に協力する。全カード共通の能力を持つ。表示要素：カード名／ID／レアリティ／カードの色／カードNo／LP（ロジックポイント。「推理」したときにこの数値と同数の証拠を獲得）／能力
- **キャラカード**：「現場」に登場して「推理」や「アクション」を行う。表示要素：カード名／ID／レアリティ／カードの色／カードNo／レベル（手札から使用するために必要なFILEエリアの枚数）／LP／AP（アクションポイント。「コンタクト」したときに相手のキャラと比較する数値）／特徴／能力
- **イベントカード**：多彩な効果を発揮する使い切りカード。表示要素はキャラカードとほぼ同様（レベル・効果など）
- **事件カード**：自分が解決すべき事件を表す。表示要素：カード名／ID／カードの色／レアリティ／事件レベル（先攻／後攻で異なる、事件解決に必要な証拠枚数）／能力／事件編・解決編マーカー
  - 事件は常に「事件編」か「解決編」のどちらかの状態
  - ゲーム開始時は必ず「事件編」
  - パートナーが「アシスト」したとき、条件（FILEエリアが7枚以上）を満たしていたら「解決編」へ移行する
  - 「解決編」から「事件編」に戻ることはない

補足：キャラのレベル・AP・LPはゲーム中に下がることがあり、下限はなくマイナスにもなり得るが、それによってキャラがリムーブされることはない。

### 2-2. カードの状態
状態はカードの向きで管理し、以下3種類。
- **アクティブ状態**（タテ向き）：通常の状態。パートナー・キャラは通常アクティブ状態で置かれる
- **スリープ状態**（横向き）：「推理」「アクション」「ガード」や、スリープが必要な能力を使うとこの状態になる
- **スタン状態**（逆向き）：「スタンさせる」効果を受けるとこの状態になる

状態遷移のルール：
- タテ向きにすることを「アクティブにする」、横向きにすることを「スリープさせる」と呼ぶ
- スタン状態のキャラは、オートフェイズやカードの効果で「アクティブにする」対象になった場合、代わりに**スリープ状態**になる（スタンは自然には解除されない）
- スタン状態のキャラが「スリープさせる」「スタンさせる」効果を受けても、状態はスタン状態のまま変わらない

### 2-3. デッキ構築のルール
1人1セット、合計42枚のカードが必要：
- パートナーカード：1枚
- 事件カード：1枚
- キャラカード＋イベントカード：あわせて40枚でデッキを作る

デッキ構築の制約：
1. デッキは**40枚ちょうど**で構築する
2. デッキに入れられるのは**キャラとイベントのみ**（パートナー・事件は入れられない）
3. 同じカード（＝同じID。絵柄が違ってもIDが同じなら同一カード扱い）は**最大3枚まで**

補足：
- デッキに入れるカードの色に制限はないが、使用時に色のルールがある（後述）
- パートナーも好きな色のカードを使用できるが、パートナーの色が能力に影響することがある

※このプロジェクトのデッキ作成画面も同一カード3枚までで実装済み（修正済み）。

### 2-4. ゲームの各エリア（プレイシート）
1. **現場**：キャラを登場させる場所。最大5枚まで置け、同じカードでも複数置ける
2. **パートナー**：パートナーやMR、特定カード（特徴「ビッグジュエル」など）が置かれる場所
3. **事件**：事件カードが置かれる場所
4. **デッキ**：デッキが置かれる場所
5. **証拠エリア**：ゲーム中に得た「証拠」が置かれる場所
6. **FILEエリア**：オートフェイズでカードが置かれる場所。アシストしたパートナーもここに移動する
7. **リムーブエリア**：リムーブされたカードや使用済みイベントが置かれる場所
8. **手札**：ここからカードを使用する。相手から見えないように持つ

補足：
- 手札や現場以外の各エリアには置ける枚数の上限はない
- 相手のエリアに自分のカードが置かれたり移動したりすることはない

### 2-5. ゲーム開始までの準備
1. 使用する事件とパートナーをそれぞれのエリアに裏向きで置く
2. デッキをよくシャッフルしてデッキエリアに置く
3. じゃんけん等ランダムな方法で先攻／後攻を決める（勝った方が先攻）
4. デッキの上から5枚引いて手札にする
5. 手札の引き直しが1回できる（引き直す場合、好きな枚数をデッキに戻してシャッフルし、戻した枚数だけ引く。先攻→後攻の順で判断）
6. 事件とパートナーを表向きにして「ゲームスタート！」

### 2-6. 勝利条件・敗北条件
- 現場にキャラを登場させ、「推理」や「アクション」で証拠を集める。必要な数だけ集まったら、パートナーの**アシスト**によって事件を解決編へ移行させ、**事件解決**を行うことでゲームに勝利する
- 敗北条件：プレイヤーが「リフレッシュ」（デッキが尽きた際の処理）を行う際、**リムーブエリアのカードが0枚だった場合、そのプレイヤーは敗北**する

### 2-7. ターンの進行
ゲームは「オートフェイズ」「メインフェイズ」「エンドフェイズ」の3フェイズで構成される「ターン」を交互に繰り返す。

**① オートフェイズ**（順番通りに実行）
1. 自分のパートナーをアクティブにする（アシストでFILEエリアに置かれていた場合はパートナーエリアに戻してアクティブにする）
2. 自分の現場にいるキャラをすべてアクティブにする（スタン状態のキャラは代わりにスリープ状態になる）
3. デッキの上からカードを1枚引き、手札に加える（先攻1ターン目も引く）
4. デッキの上から2枚（**先攻1ターン目のみ1枚**）を、1枚ずつ裏向きのままFILEエリアに置く

FILEエリアのカードの置き方：カードには順番があり、**最も新しく置かれたカードが1番上**になるように、1枚ずつ置く。

**② メインフェイズ**：以下6つの行動を好きな順番・好きな回数で行える（一部例外あり）
1. 手札の使用（1ターンに1回まで）
2. ネクストヒント
3. パートナーの能力の使用
4. キャラの【宣言】能力の使用
5. 推理
6. アクション

補足：他の行動中や効果の解決中は次の行動に移れない（割り込み不可）。番号は順番を表すものではない。

**③ エンドフェイズ**
1. ターン終了時の能力が発動し、効果を解決する
2. ターン終了時までの効果が切れる
3. ターンエンドを伝えて相手のターンに移る

### 2-8. メインフェイズの行動詳細

**01. 手札の使用**（1ターンに1回まで。このターン中に「ネクストヒント」を行っていた場合は行えない）
- 手札から、自分のFILEエリアの枚数**以下**のレベルのカードを1枚使用する
- キャラを使用した場合：アクティブ状態で現場に登場
- イベントを使用した場合：効果を解決してリムーブエリアへ
- FILEエリアの枚数は、アシスト中のパートナーも数える
- 使用するカードは自分の事件の色による制限を受ける（後述）

**色の制限**：「手札の使用」「ネクストヒント」では、自分の事件と同じ色を持つカードのみ使用できる。2色カード（2色MR）を使用するには、自分の事件がその2色を両方持っている必要がある。2色カードはどちらの色としても扱われる。
- 例外：能力によってキャラを「登場させる」場合、カットイン、変装は色制限を受けない

**スイッチ**：現場は5枚までだが、埋まっている場合、既にいるキャラをリムーブして新しいキャラを登場させられる（スイッチ）。リムーブするキャラに状態の条件はない。現場が埋まっている場合か、複数体同時登場で上限を超える場合のみ行える。

**02. ネクストヒント**：FILEエリアのカードを消費してカードを1枚使用できる
1. 自分のFILEエリアの1番上のカード（アシスト中のパートナーを除く）を手札に加える
2. 手札から、自分のFILEエリアの枚数以下のレベルのカードを1枚使用できる（しないことも選べる）
- ②で使用できるのは1回のネクストヒントにつき1枚
- ②の際、①で加えたカードはFILEエリアの枚数に数えない
- ①②の間に他の行動を挟むことはできない
- FILEエリアにカードがない場合は行えない

**03. パートナーの能力の使用**：パートナーは「アシスト」と「事件解決」の2つの能力を持つ。どちらもスリープが必要なアイコンがあるため、パートナーがアクティブ状態でなければ使用できない。

- **アシスト**：
  1. パートナーをスリープさせ、FILEエリアに移動させる（ここにいる間はFILEエリアの枚数として数える）
  2. このときFILEエリアにパートナーを含めて**7枚以上**あれば、事件は解決編へ移行する（マーカーを裏返す。移行条件を満たしたら必ず移行し、移行させないことは選べない）

- **事件解決**：
  - 「事件解決」を宣言し、パートナーをスリープさせる。自分の事件の事件レベル以上の証拠が集まっていれば勝利
  - 事件が解決編でなければ行えない
  - パートナーは「推理」を行うこともできる

**04. キャラの【宣言】能力の使用**：以下が持つ【宣言】アイコン付き能力を使用できる
- 自分の現場にいるキャラ
- 自分の事件
- 自分のパートナーエリアにいるMR
手順：①能力の使用を宣言しコストをすべて払う → ②効果を解決する
- 他の行動・効果解決中に割り込んでは使用できない
- 登場したターンからすぐに使用できる（名乗り状態でも可）
- アクティブ状態でなくても使用できる（ただしコストに「スリープさせる」があるものは、スリープ状態・スタン状態では使用不可）
- コストに「：」がある能力は、コストをすべて払うことで使用可能（一部でも払えない場合は不可）。コストのテキストは「自分の」が省略されている（相手のカードはコストにできない）
- コストで行ったことは「自分の能力や効果によって～したとき」の条件を満たさない

**05. 推理**：パートナーやキャラのLPを活かして証拠を増やす
- アクティブ状態のパートナー、または自分の現場にいるアクティブ状態のキャラが行える
- 現場に登場したターンはまだ推理できない（「名乗り状態」）。ただし「迅速」を持つキャラは登場ターンからすぐ推理可能
- 手順：①推理を宣言し、推理するパートナー／キャラをスリープさせる → ②推理したパートナー／キャラのLPの数だけ証拠を得る（デッキの上から証拠エリアに裏向きで置く。LPが0以下なら証拠は得られない） → ③相手はミスリードを行える → ④推理終了
- 証拠エリアのカードもFILEエリアと同様、最も新しいカードが1番上になるように1枚ずつ置く（2枚以上得る場合も1枚ずつ）
- 先攻1ターン目から行える。回数制限はなく、アクティブに戻れば何度でも推理できる

**06. アクション**：相手の現場のキャラを減らす、または相手の証拠を減らして自分の証拠を増やす
- 自分の現場にいるアクティブ状態のキャラが行える。名乗り状態では行えない（「迅速」または「突撃」を持つキャラは登場ターンからすぐ可能）
- 回数制限はなく、アクティブに戻れば何度でも行える
- 対象は以下の2種類のどちらか：
  - **アクション［キャラ］**：相手の現場にいるキャラ（スリープ状態かスタン状態のもの）
  - **アクション［事件］**：相手の事件（証拠が1つもない事件は対象にできない）
- 手順：①対象を指定してアクションを宣言し、アクションするキャラをスリープさせる → ②相手はガード（現場のアクティブ状態のキャラ1枚でガードし、そのキャラをスリープさせる。名乗り状態でもガード可能、AP等の条件もない）を選べる
  - アクション［キャラ］がガードされなかった場合 → コンタクト発生（相手の現場のキャラとの間で）
  - ガードされた場合 → コンタクト発生（ガードしたキャラとの間で）
  - アクション［事件］がガードされなかった場合 → 「アクション［事件］がガードされなかった」の処理へ
- アクション中のキャラやアクション対象のキャラが、ガードまでの間に現場を離れた場合はアクションはその時点で終了する

**コンタクト**（アクションがガード、または対キャラで発生した際の攻防処理）
1. **行動順の確認**：APを比べ、**低い方が1番目、高い方が2番目**に行動する（APが同じ場合はアクションされた側＝非ターンプレイヤーが1番目）
2. **1番目の行動**：各プレイヤーは「カットイン」か「変装」を使うか、パスを選択（1回のコンタクトにつきどちらか1回まで）
3. **2番目の行動**：同上。1番目がパスし2番目が行動していた場合、1番目が改めて行動できる
4. **APの判定**：アクションしたキャラのAP ≧ 相手キャラのAP → 相手キャラをリムーブ／アクションしたキャラのAP ＜ 相手キャラのAP → 何も起こらない（APが同じでもリムーブされる。アクションしたキャラ自身はリムーブされない）
5. **コンタクトの終了**：コンタクト中の効果（カットインのAP＋など）が切れる
6. **アクションの終了**：アクション終了時の能力が発動・解決、アクション中の効果が切れる

補足：コンタクト中のいずれかのキャラが現場を離れたら、その時点で手順を進める。「コンタクトを発生させる」効果によるコンタクトはここで終了する。

**コンタクト中に使える行動**（1回のコンタクトにつきどちらか1回・1枚まで）
- **カットイン**：手札から「カットイン」を持つカードを使い、コンタクトを支援する（使用後リムーブエリアへ）。例：「カットイン：AP＋2000」＝コンタクト中のキャラをAP＋2000する効果（コンタクト終了時に切れる）。1回につき1枚のみ、2枚以上は使用不可。1枚に「カットイン」効果が2つ以上あっても1つだけ選んで使用。自分の事件と同じ色を持たないカードでも使用可
- **変装**：手札にある「変装」を持つキャラカードを、コンタクト中のキャラと入れ替える（入れ替わったキャラがコンタクトしている扱いに）。元のキャラは裏向きでデッキの下に移す。変装したら元のキャラの状態や受けていた効果（スリープ状態、能力・効果、セット／重ねられたカード等）を引き継ぐ。変装での入れ替わりは「登場」ではないため、登場時能力は発動しない。変装したこと自体で、そのキャラの「変装」の能力が発動する

**アクション［事件］がガードされなかった場合の処理**
1. 相手の1番上の証拠をリムーブする（リムーブする証拠が「ヒラメキ」を持っていた場合、相手はヒラメキを発動させて効果を解決できる。発動させないことも選べる。解決／非発動を選んだらリムーブエリアへ）
2. 自分は証拠を1つ得る
3. アクション終了時の能力が発動・解決、効果が切れる
- リムーブする相手の証拠・自分が得る証拠は、アクションしたキャラのLPに関わらず**常に1つ**
- アクション中のキャラが現場を離れてもこの処理は最後まで進む
- 表向きの証拠でも、アクション［事件］でリムーブされればヒラメキは発動できる。アクション［事件］以外（能力・効果）でリムーブされた場合はヒラメキは発動しない
- ヒラメキの効果解決中は、そのカードはまだリムーブエリアに置かれていない扱い（リフレッシュでシャッフル対象にならない）

### 2-9. リフレッシュ（デッキ切れの処理）
デッキがなくなった時点で即座に行う：
1. リムーブエリアのカードをシャッフルしてデッキに置く
2. 相手は証拠を1つ得る

補足：
- 行動や効果解決の途中でデッキが尽きても即座にリフレッシュを行い、その後で残りを解決する
- イベントやコンタクト解決中のカードなど、効果解決が終わるまではまだリムーブエリアに置かれていない扱い（＝シャッフル対象に含まれない）。ただしヒラメキ・ミスリードは、リムーブエリアに置かれた状態で効果を解決する（＝シャッフル対象に含まれる）
- 「デッキの上から○枚リムーブしてもよい」等、指定枚数を満たせない場合は行えない
- 「デッキの上から見る／公開する」効果は、指定枚数に満たなくても可能な範囲で行い、リフレッシュは発生しない
- 「デッキの上から○枚リムーブする」（強制）でデッキが足りない場合は、残りすべてをリムーブしてからリフレッシュする（不足分は後からリムーブしない）

### 2-10. 能力と効果
能力のタイプは大きく2種類：
- **（現場で）常に有効な能力**：そのキャラが現場にいる限り自動的に有効になる（エリア指定がある能力は現場以外でも有効）
- **条件を満たしたときに効果が発動する能力**：「～したとき」「～するたび」「～時」等の条件を満たすと発動する。発動回数に上限があっても、その範囲内なら発動を拒否できない。同じキャラが複数現場にいる場合、条件を満たした瞬間すべて同時に発動する（解決順は自由に選べる）

**能力や効果の「有効」について**：アイコンで示された条件を1つでも満たさない場合、そのテキストは有効でなくなる。
- 有効でない能力は、他のカードから参照できない
- 有効でなくなった場合の扱い：常に有効な能力→効果が発揮されなくなる／条件発動型→発動しない／【宣言】→使用不可／カットイン・変装→使用はできるが何も起こらない／ヒラメキ→発動はできるが何も起こらない／イベント→使用はできるが何も起こらない
- 能力（アイコン自体）を参照する場合はテキストが有効でなくても参照可能。「無効にする」効果を受けた場合は何も起こらない

**効果テキストの原則**：
- 「～する」は必ず行う（一部解決不可なら可能な範囲で行う）。「～してもよい」は行わないことを選べる
- 例外的に即座に解決する効果：「～とき、代わりに～」「～とき、無効にする」
- 発動した効果は、現在の行動・効果解決が完了してから解決できる（それまでは「未解決」）。未解決の効果が複数ある場合、そのカードの持ち主が好きな順で解決可能。複数プレイヤーの未解決効果がある場合はターンプレイヤーのものを優先
- エリア指定なく「キャラ」とあれば現場にいるキャラを指す。「～枚まで選び」は自分・相手どちらの現場のキャラも選べ、発動したキャラ自身も選べる。「～枚まで」は0枚選択も可能

### 2-11. カードのセット／重ね
- **セット**：効果でカードをキャラに「セットする」場合、そのカードは枚数・能力を確認できる形でキャラの下にずらして置かれる。セットできる枚数に制限はない。裏向きでセットされたカードの中身は確認できず、キャラともイベントとしても扱われない（リムーブ時は表向きにしてリムーブエリアへ）。セットしたキャラが現場を離れる／別キャラの下に重なる場合、セットされたカードはすべてリムーブされる
- **重ね**：「カードを下に重ねる」効果は、セットとは異なり枚数以外の情報を持たない。キャラが現場を離れる／別キャラの下に重なる場合、重なっているカードもすべてリムーブされる

### 2-12. アイコンの意味
- **登場時**：このキャラが現場に登場したとき発動（能力・効果による登場でも発動）
- **リムーブ時**：このキャラが現場からリムーブされたとき発動（方法は問わない）
- **変装時**：このキャラが変装で現場に現れたとき発動
- **一番乗り**：このキャラが自分の現場にこのターン最初に登場したとき発動（能力による登場・相手ターン中の登場・同時複数登場でも条件を満たせば発動）
- **回数制限アイコン**：各ターン1回だけ／各ターン2回まで、等
- **有効条件アイコン**：自分のターン中／相手のターン中／自分のパートナーが指定の色を持つ／自分の事件が指定の色・特徴を持つ（2色以上ある場合、指定色を1つでも持てば有効。＆指定は全部必要）／自分のFILEエリアが指定枚数以上（アシスト中パートナーも数える）／事件編である／解決編である／現場に指定のカード名のキャラがいる（パートナーでは条件を満たさない）

### 2-13. キーワード能力（太字表記）
- **迅速**：名乗り状態でも推理・アクションできる
- **突撃**：名乗り状態でもアクションできる
- **突撃［キャラ］**：名乗り状態でもアクション［キャラ］できる
- **突撃［事件］**：名乗り状態でもアクション［事件］できる
- **ブレット**：このキャラのアクションはガードできない
- **ミスリードX**：相手が推理したとき、自分の現場のアクティブ状態のミスリード持ちキャラをスリープさせることで、推理したパートナー／キャラをLP−Xする（効果はその推理の終了時まで）。1回の推理に対して何枚でも同時に使用可能
- **捜査X**：相手はデッキの上からX枚公開し、相手の好きな順でデッキの下に移す。公開されたカードはその後の効果で「発見された」カードとして扱う（デッキがX枚ない場合は残り全部を公開）
- **痕跡**：このゲーム中に相手がリフレッシュしたとき、自分は「痕跡［発見済み］」状態になる（一度なったらゲーム中ずっと継続）。自分のリフレッシュでは発見できない

補足（名乗り状態Q&A）：
- 名乗り状態のキャラが突撃を得ても、その時点で強制的にアクションする必要はない（メインフェイズ中いつでも可）
- 名乗り状態で突撃を持つ（迅速は持たない）キャラがアクションし、そのターン中にアクティブになっても、そのターン中は名乗り状態のままなので推理はできない

### 2-14. MR（拡張パック第5弾「新たなる謎」〜登場）
MRは通常カードと同様に使用・現場登場できるキャラだが、特別ルールを2つ持つ：
- 自分の現場に新たなMRが登場する場合、既に現場かパートナーエリアにいるMRはリムーブされる（同じカードかどうかは問わない）
- 相手ターン中に現場を離れる場合、パートナーエリアに移動する（自分のターン中に離れる場合は移動せずそのまま現場を離れる）
  - パートナーエリアへの移動は、離れた先のエリアに一度置かれてから即座に行われる扱い（＝リムーブ時発動の能力はMRのリムーブでも発動する）
  - 現場を離れる方法は問わない
- パートナーエリアにいるMRは推理・アクションはできないが、パートナーエリアでも発動する能力や【宣言】能力は使用できる

### 2-15. キャラの名前が複数あるカード名のルール／特殊な効果
- 例：《江戸川コナン＆工藤新一》は、あらゆるエリアで「江戸川コナン＆工藤新一」「江戸川コナン」「工藤新一」の**すべてのカード名を持つ**ものとして扱う（現場にいれば「江戸川コナン」を参照する【絆】能力なども有効になる）
- 《江戸川コナン＆工藤新一》と《江戸川コナン》を同時に選んで下に重ねる、といったことはできない
- 現行ルールでは「＆」「（）」で名前が複数書かれているカードにのみこのルールが適用される
- **元のLP／APを0にする効果**：その数値が0として扱われる（他の効果による増減は別途そのまま残る。APが0になってもそれ自体でリムーブはされない）
- **元の能力を無効にする効果**：もともと書かれている能力がすべて無効になる（他のカード由来の能力やすでに発動済みの効果は無効にならない。MR能力はこれでは無効にならない）

## 3. 盤面デザインで指示した方針（時系列）

### レイアウトの基本方針
- 公式サイト（takaratomy.co.jp）の「プレイシートとカードの置き方」ページを参照し、実際のプレイシート画像に配置を厳密に合わせた
- 配置：事件（左上）／現場（上部中央・横長）／デッキ（右上）／証拠エリア（左端・縦長）／パートナー（中央）／リムーブエリア（右端・縦長）／FILEエリア（中央下・横長）
- 現場・パートナー・FILEの3エリアは幅を統一（キャラカード5枚がちょうど収まる幅＝720px）し、すべて中央揃え
- 現場・パートナー・FILEの背景は薄いクリーム色のバンドで統一

### カードの見た目・重なり表現
- FILEエリア：カードが横に重なって並ぶ表現。最大10枚を基準にした間隔で、実際の枚数（例：5枚、8枚）に関わらず同じスロット位置に来るよう固定
- 証拠エリア：カードが縦に重なる表現。同様に最大枚数基準で間隔を統一
- カードの縁取りはすべて白線に統一（重なりを視認しやすくするため）
- 各エリアの「枚数表示」は数字バッジ（丸い白背景）に統一し、「〜エリア 7枚」のような冗長なテキストラベルは削除
  - 例外：パートナーエリアには数字バッジ不要（1枚固定のため）
- デッキ・リムーブエリアにも残り枚数を数字バッジで表示

### 相手側（上下左右反転）の実装
- 自分側のレイアウトを180度回転させて相手側を作成
- 単に配置場所を反転するだけでなく、カードが「積まれていく向き」も反転させる必要があった
  - 証拠エリア：自分側は上から下に積む、相手側は下から上に積む（事件カードに近い側が正面カード）
  - FILEエリア：自分側は左から右、相手側は右から左に積む
  - この「向きの反転」を最初は見落としており、後から修正した
- 相手の手札は裏向きで表示。自分の手札と同じ「向き」（左が奥・右が手前の重なり方）にしつつ、位置はFILEエリアに重ならないよう独立させる

### 手札の表現
- 自分の手札はマスターデュエル風の扇状配置、表向き
- 「手に持っているイメージ」を再現するため、FILEエリアに少し重なる形にした（重なり具合は都度調整）
- 重なり順（z-index）は左から右に向かって手前に来るよう設定（右端のカードが一番手前）

### 配色
- 初期は紫〜ピンクのグラデーションだったが「既存デザインのパクリになる」との指摘で変更
- ダークネイビー〜ウォームブラウン（ゴールド寄り）のグラデーションに変更。夜の捜査ボード・古い手帳のようなミステリー感を意識

### バグ修正の記録
- FILEカードが表示されない問題：CSSでカードの背景・枠線が未定義だったため発生、修正
- 証拠カードの幅が枠からはみ出す問題：カードは横向き（幅174px）なのにエリア幅が170pxしかなかったため発生、列幅を200pxに拡大
- 証拠エリアの左右中央揃えが崩れる問題：JSで計算したコンテナ幅（EVI_CW/EVI_CHパラメータ）と、実際の見た目サイズ（CSSのvar(--card-h)固定値174px）が一致していなかったのが原因。buildFan関数内で明示的にwidth/heightをインライン指定するよう修正
- 左上に謎の要素が出る問題：「事件」「現場」「デッキ」等の各ラベルがposition:absoluteなのに、親要素にposition:relativeが設定されておらず、一番近いposition:relative祖先（.table）を基準に全ラベルが左上に重なって表示されていた。各親要素にposition:relativeを追加、またはラベル自体をposition:staticに変更して解決

### 出力サイズ
- 最終的に盤面全体を1080×1920（スマホ縦画面向け）の固定キャンバスに収める形に変更
- JSで実際のコンテンツ幅を計測し、スケール値を計算して中央配置
- 当初は左右に余白ができていたが、原因は`.table`要素自体の幅が1720px固定になっていたため（中のグリッドはもっと狭い）。`width:max-content`に変更して解消し、横幅いっぱいに表示されるようにした

## 4. exe化（Electronパッケージング）の方針
- 「パソコンでexeで開けるようにして」という要望に対し、以下を選択肢として提示：
  1. HTMLファイルのままダブルクリックで開く（exe化不要）
  2. Electronでexe化する（少し時間がかかる）
- ユーザーはexe化を選択
- 実装内容：
  - `main.js`：Electronのメインプロセス。ウィンドウを作成し`index.html`を読み込む
  - `electron-packager`を使い、Windows x64向けにパッケージング（Linux環境からのクロスビルドのため、アイコンやバージョン情報の埋め込み＝rceditにはWineが必要でエラーになったが、`package.json`から`version`フィールドを削除することでrceditの実行条件を回避し、パッケージング成功）
  - 出力：`ConanTCGViewer-win32-x64.zip`（約104MB）。解凍して`ConanTCGViewer.exe`をダブルクリックで起動
  - 注意点：フォルダ全体が一式必要（Electron本体を含むため）。exe単体だけを移動しても動かない

## 6. 「AIが対戦する動画を撮りたい」という目標に対する整理

### 現状でできること
- Windows標準の画面録画（Xbox Game Bar / Win+G）やOBS Studioで、exeのウィンドウをそのまま録画することは今すぐ可能
- ただし現状は静止した1つの盤面を表示しているだけなので、録っても「静止画の動画」にしかならない

### 動く対戦動画にするために必要な要素（4段階で整理）

**① ゲーム状態のデータモデル化**
今はHTMLに直接カード名を書いているが、これをJSON等のデータ構造に置き換える必要がある。
```json
{ "hand": [...], "field": [...], "evidencePile": [...], "fileArea": [...], "deck": [...] }
```

**② ルールエンジンの実装**
「このアクションは合法か」「実行したら状態がどう変わるか」を判定するロジック。
例：現場にキャラを出す／証拠を獲得する／事件を解決する、などを関数化。
ここが一番手間がかかる部分。

**③ AI（意思決定ロジック）の実装 — 段階的に**
- **Lv1：ランダムAI** — 合法手からランダムに選ぶだけ。まず「動く」ことの証明用
- **Lv2：ルールベースAI** — 「LP合計が一番高いキャラを出す」「証拠が取れるなら取る」等の単純なスコアリング。動画用途ならこのレベルで十分「それっぽく」見える
- **Lv3：探索型AI** — 数手先を読んで評価する（将来的な拡張）

**④ 対局ログの出力 → ビューアでの自動再生**
AI同士に1試合分プレイさせ、各ターンの状態変化をJSONログとして記録。
そのログをビューアに読み込ませ、1手ずつ盤面を更新するアニメーションを実装すれば「対戦動画」として録画できる状態になる。

### 提案した進め方
1. まず①状態モデル＋②ルールエンジンの最小版（現場に出す・証拠を取る・事件解決くらいの範囲）を実装
2. ③ランダムAIで1試合動かしてログを出力できるところまで作る
3. ここまでできれば「動く」ことが確認できるので、そこから先（ルールベースAI化、アニメーション再生、動画撮影）に進むかを判断する

→ この方針に着手するかどうかは次回相談待ち。

### AIの意思決定優先順位（指示済み・実装はまだ）
ユーザーから、AIが手を選ぶ際の優先順位について以下の指示があった。実装はまだ着手していないが、ルールベースAI（Lv2）を作る際はこの優先順位に従う。

1. **このターン中に事件解決できるなら、その動きを最優先で実行**
2. **次の相手ターンに負けず、かつ次の自分のターンに勝てる動き**
3. **相手の現場のキャラを全除去する動き**
4. **このターン中に負けないようにする動き**
